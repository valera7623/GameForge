# Пользователи и роли

## Роли платформы

| Роль | Возможности |
|------|-------------|
| `user` | Инструменты, свои проекты |
| `enterprise` | Устаревшая платформенная роль (план обычно в подписке) |
| `support` | Админка: просмотр пользователей, генераций, дашборда |
| `manager` | То же чтение, что у support |
| `admin` | Пользователи (блок/правка/роль кроме `super_admin`), инструменты, подписки |
| `super_admin` | Полный доступ, включая настройки платформы |

Роли **организации** Studio (`owner` / `admin` / `member`) отдельны от глобального `UserRole`.

## Админ-панель

Вход сотрудников: **`/admin/login`** (или **`/admin`** после входа со staff-аккаунтом).

API: `/api/v1/admin/*` (cookie-сессия, как у приложения).

| Раздел | Путь |
|--------|------|
| Дашборд | `/admin` |
| Пользователи | `/admin/users`, `/admin/user?id=` |
| Генерации | `/admin/generations` |
| Подписки | `/admin/subscriptions` |
| Инструменты | `/admin/tools` |
| Настройки | `/admin/settings` (запись — super_admin) |

Отключённые инструменты отвечают **503** на эндпоинтах генерации.

## Seed

```bash
docker compose exec api python scripts/seed_db.py
```

Создаёт demo/admin только если `APP_ENV` не `production`. В проде скрипт завершается с ошибкой.

Локальный admin: `admin@gamedev.ai` / `admin123456`, роль **`super_admin`**.

!!! danger "Не сидите production"
    Не ставьте `SEED_ON_DEPLOY=1` на живом VPS. Удалите остатки `demo@` / `admin@`.

## Сброс пароля

Нужна рабочая почта (`resend` / `smtp`). Пользователь открывает `/reset-password` по токену из письма.
