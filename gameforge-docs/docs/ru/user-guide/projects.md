# Проекты

Проекты группируют ассеты одной игры и движка.

## Создание

1. Откройте **Projects** (или создайте из формы инструмента).
2. Укажите **имя**, опционально **описание** и **engine** (`unreal`, `unity`, `godot`, `other`).
3. Сохраните — получите `project_id` для API.

## Привязка генераций

Большинство инструментов принимают опциональный `project_id` — результаты попадают в историю и экспорт.

## Экспорт

```bash
curl -s -X GET "http://localhost:8000/api/v1/projects/$PID/export" \
  -H "Authorization: Bearer $TOKEN" -o game-assets.zip
```

В UI используйте действие экспорта проекта.
