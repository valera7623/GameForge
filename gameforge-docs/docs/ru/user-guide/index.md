## Типичный сценарий

1. Регистрация или вход.
2. Создайте **проект** (движок: Unreal / Unity / Godot / Other).
3. Откройте инструмент с дашборда или сайдбара.
4. Отправьте промпт (при необходимости с `project_id`).
5. Скачайте ассет; экспортируйте ZIP проекта.

Лимиты генераций зависят от тарифа — см. [Биллинг](billing.md).
