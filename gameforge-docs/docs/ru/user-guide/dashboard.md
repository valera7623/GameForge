# Dashboard

Главный экран после входа.

## Что видно

- **Профиль / план** — подписка и остаток генераций
- **XP и ачивки** — +10 XP за генерацию
- **Launch a tool** — быстрый запуск семи инструментов
- **Недавняя активность** — последние генерации

На узких экранах сайдбар уходит в гамбургер; панель «Launch a tool» на мобиле может скрываться — используйте пункты меню.

## Советы

- Привязывайте генерации к **проекту** для последующего экспорта.
- При ошибке валидации проверьте обязательные поля (особенно описание в Character Creator).
- Тема и язык (EN/RU) переключаются в интерфейсе приложения.
