# Команда

На тарифе Studio можно приглашать коллег и делить места.

## Требования

- Активный план **Studio** (или выше), либо on-prem `FORCE_PLAN=enterprise`
- Страница **Team** в UI

## Сценарий

1. Апгрейд до Studio (или on-prem план).
2. Создаётся организация (или `POST /api/v1/orgs`).
3. Инвайт по email.
4. Принятие через ссылку accept-invite.

## Роли

Роли организации отдельно от глобального `UserRole`. Админы платформы — см. [Пользователи](../admin-guide/users.md).

## Почта

Инвайты и reset пароля в проде требуют `EMAIL_PROVIDER=resend` или `smtp`. Режим `console` пишет только в логи API.
